# The Nature Explore 🌿

**Explore beyond the map.**

A responsive travel and nature discovery website for **The Nature Explore** — focused on hidden places, scenic roads, road trips, weekend escapes, destinations, and outdoor stories.

## ✨ Features

- Fully responsive design for mobile, tablet, and desktop
- Premium travel-focused homepage
- Responsive mobile navigation
- Destination discovery and detailed destination guides
- Road-trip guides and route information
- Travel stories section
- Responsive photo gallery
- Fullscreen image lightbox
- Google Maps route embeds on destination pages
- Destination facts, highlights, itineraries, and travel tips
- Instagram call-to-action
- SEO-friendly metadata
- Accessible navigation and controls
- Reduced-motion support
- Static-site architecture with no backend or database requirement

## 🗺️ Destinations

The website currently includes destination guides for:

### Karnataka

- **Coorg (Kodagu)** — coffee country, waterfalls, scenic roads and Western Ghats
- **Chikmagalur** — coffee estates, Mullayanagiri, Baba Budangiri and waterfalls
- **Mysore** — heritage, palaces and culture
- **Nandi Hills** — sunrise rides and hill roads near Bengaluru
- **Adiyogi, Chikkaballapur** — spiritual landmark and weekend escape
- **Kotilingeshwara** — temple destination and day-trip experience
- **Devarayanadurga (DD Hills)** — forested hills, viewpoints and road-trip routes
- **Kailasagiri Hills** — hill escape and scenic viewpoints
- **Cubbon Park** — Bengaluru's iconic green space
- **Bannerghatta Zoo** — wildlife and nature experience near Bengaluru

### Tamil Nadu

- **Yercaud** — misty hills, lake, viewpoints and winding roads
- **Rameshwaram** — coastal landscapes, temples and island road-trip experience

### West Bengal

- **Victoria Memorial, Kolkata** — heritage, architecture and city exploration

Each destination page is designed to include sample photography, highlights, travel information, maps, routes and suggested itineraries. Original photographs can be added later.

## 🚀 Deployment

The website is a static HTML/CSS/JavaScript project and can be hosted on platforms such as Render Static Sites, GitHub Pages, Netlify, or Vercel.

### Render

1. Create a **Static Site**.
2. Connect this GitHub repository.
3. Select the `main` branch.
4. Use the repository root as the publish directory.
5. Deploy.

No server-side runtime or database is required.
