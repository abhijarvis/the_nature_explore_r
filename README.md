# The Nature Explore 🌿

A responsive travel and nature discovery website for **The Nature Explore** — focused on hidden places, scenic roads, road trips, weekend escapes, and outdoor stories.

## ✨ Features

- Fully responsive design for mobile, tablet, and desktop
- Modern travel-focused landing page
- Mobile hamburger navigation
- Road-trip and destination discovery cards
- Travel story section
- Responsive photo gallery
- Fullscreen image lightbox
- Instagram call-to-action
- SEO-friendly metadata
- Accessible navigation and controls
- Reduced-motion support
- Lightweight single-page architecture

## 🗂️ Project Structure

```text
.
├── index.html   # Complete website
└── README.md    # Project documentation
```

The current site is intentionally simple and can be deployed as a static website without a backend.

## 🚀 Deployment

The website can be hosted on any static hosting platform, including Render Static Sites, GitHub Pages, Netlify, or Vercel.

### Render

1. Create a **Static Site**.
2. Connect this GitHub repository.
3. Select the `main` branch.
4. Use the repository root as the publish directory.
5. Deploy.

No server-side runtime or database is required.
